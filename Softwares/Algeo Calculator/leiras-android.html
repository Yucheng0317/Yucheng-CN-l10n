主要功能

计算器： 输入时表达式会自动计算。要添加一行新的计算，按 ENTER↵ 键。向上滚动以查看以前的计算。要在弧度和度之间切换，请按键盘顶部的选项按钮。NaN 表示“不是一个数字”。按 'Ans' 可获取最后的答案。注意：最后的答案必须是数字，例如，微分的结果不会改变 'Ans' 的值。

如果您按 ^ 或 /，Algeo 会智能地放置指数和分母。例如，按下 2 然后 ^，光标会跳到指数级。在这里，您可以输入指数。当您想跳回正常水平时，只需在表达式右侧的空白区域点击即可。您也可以使用方向键移动光标。

使用变量： 有四个变量： a、 b、 d 和 t （字母 c 保留用于光速常数）。您可以通过长按相应的数字输入它们。变量的默认值为 0。要设置它们的值，请使用 '='。示例：
a=2+1
a^2 → 9

常量： 在 CONST 按钮下有几个预定义的物理常量。它们包括数学常数，如 e 或 π 以及其他数字，如光速或重力。

使用图形： 您可以通过触摸移动图形。要缩放，请使用右下角的按钮。您可以通过选择上方工具栏中的 Trace 图标来追踪函数。在每个绘图线上会出现一个点。用手指在屏幕上移动以移动点。它会自动吸附到函数的交点和根部。在屏幕的上方，您将看到在点处评估的绘制函数的值。

可以绘制极坐标图，而不是常规的笛卡尔函数。要使用极坐标，在图形输入屏幕中，点击右上角的“笛卡尔”将其切换到极坐标模式。在这里，变化的变量是 θ，而不是 y。

值表： 您可以在图形菜单中生成您指定的函数的数值表。只需按下 Table 按钮。显示将显示给定间隔内函数的值列表。您可以通过按顶部栏上的“设置”图标来修改范围设置。按下“重置范围”将范围设置为区间 [1;10]。

高级功能

解方程： solve 函数将解给定的表达式中的 x。如果方程中没有 = 符号，它将为 0 解方程。因此在下面的例子中，它解方程 x^2=0。它只找到一个解。示例：
solve(x^2) → 0
solve(sinx=cosx) → 0.785398

微分： 您可以使用 diff 函数进行微分。它的唯一参数是要微分的表达式。示例：
diff(x^2) → 2*x
diff(tg(x)) → cos(x)^(-2)
diff(diff(sin(x))) → -sin(x)

积分： 使用 int 函数计算一个函数的定积分。第一个参数是要积分的函数，其他两个是积分的上下限。示例：
int(x,0,10) → 50
int(sinx,-1,1) → 0

泰勒级数： 要计算函数的泰勒级数，使用 taylor 函数。第一个参数是函数，第二个参数是泰勒级数的中心点，第三个参数是最大项的指数。示例：
taylor(ln(x),1,3) → x-1-(x-1)^2/2!+(x-1)^3/3!
taylor(sinx,0,4) → -x^3/3!

组合数学： 两个组合函数 nPr 和 nCr 让您计算排列和组合。nPr 计算 n 的 r-排列的数量。它给出了从 n 个元素中选择 r 个元素并排成一行的方式数量。nCr 计算具有 n 个元素的集合的 r-组合的数量。它给出了从 n 个元素中选择 r 个元素的方式数量。示例：
nPr(5,2) → 20
nCr(5,3) → 10

统计： 您可以使用 mean 和 median 函数计算一组数字的均值和中位数。stddev 函数计算标准差（方差的平方根）。示例：
mean(1,5,10) → 8
median(1,5,10) → 8
此外，normal 函数为您提供正态分布的密度函数。第一个参数是计算函数的点，第二个是均值，第三个是标准差。示例：
normal(1,0,2) → 0.17
尝试绘制 normal(x,0,1) 以获得标准的钟形曲线！

其他功能： 上述未解释的函数列在下表中：

函数 描述 示例

单位

Algeo 智能处理测量单位。它自动将单位转换为正确的形式：
5m+2cm → 5.02m
你可以看到，厘米被转换为米并相加。你也可以自由混合 SI 单位和英制单位：
5m+1yd → 5.9144m
如果你想以其他单位显示结果，点击结果旁边的三个点，选择“更改单位”。输入新单位，更新的结果将会显示：
5m+1yd → 6.46806yd

不同类型的单位也可以混合使用，比如长度和时间。让我们解决以下问题：一只猫在 3 分钟内走了 50 米。它的速度是多少米每秒？只需将长度除以经过的时间即可得到：
50m/3min → 0.27m/s
你可能需要通过“更改单位”菜单将结果的单位更改为 m/s。
